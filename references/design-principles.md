# 设计师视角（v7 新增：让 Skill 更懂设计师）

Skill 之前只回答"长什么样"，这份补"为什么这样"——设计师做决策时的思考方式。
用它来做三件事：选组件、选风格、点评设计稿。

## 1. 组件选用决策树

```
用户要做"选择"？
├─ 选项 ≤ 5 个、常驻页面 → 26 TAB切换（顶部横滑）
├─ 选项 ≤ 5 个、页面底部 → 03 底部TAB（主导航）
├─ 要做营销按钮 → 23 按钮/标签（胶囊+动词+角标）
└─ 表单里的选择 → 29 表单输入（单选/多选/开关）

用户要做"钱"？
├─ 展示等级/身份 → 22 会员卡片（大字等级+3D徽章+进度条）
├─ 卖东西/抢购 → 24 秒杀/拼团（暖色头图+倒计时+价格三件套）
├─ 充值/打赏 → 04 底部弹窗（金额宫格+首充角标）
└─ 账单/明细 → 31 订单卡片（状态色+时间线）

用户要做"人"？
├─ 个人中心 → 20 个人主页（用户区→数据行→会员横幅→宫格→列表）
├─ 对战/竞技 → 21 PK组件（红vs蓝+中央VS+比分条）
├─ 排行榜 → 20 排行榜单（前三领奖台+4-N列表+我的排名条）
└─ 社交名片 → 17 卡片设计（挂牌/档案式）

用户要做"营销弹窗"？
├─ 操作型（选课/充值/设置）→ 04 底部弹窗（底部升起）
└─ 领奖型（券/红包/抽奖）→ 28 异形弹窗（中央悬浮+异形容器）

用户要做"信息流"？
├─ 顶部大视觉 → 25 顶部视觉（渐变底+描边大字+吉祥物右半屏）
├─ 通知/公告 → 08 公告跑马灯
└─ 加载失败/没内容 → 30 空状态与异常页（吉祥物+一句话+CTA）
```

## 2. 风格选用指南

| App 品类 | 首选 | 备选 | 避开 |
|---|---|---|---|
| 社交/社区 | 黏土可爱 | 手绘风 / 新丑风（Z 世代） | 暗黑霓虹（日间用） |
| 电商/促销 | 黏土可爱 | 多巴胺（大促氛围）/ 国潮（大促） | 极简奶油（缺紧迫感） |
| 儿童/教育/宠物/运动 | 手绘风 | 多巴胺 / 扁平插画 | 暗黑霓虹 |
| 音乐/游戏/电竞 | 暗黑霓虹 | 液态玻璃（播放器） | 手绘风（缺酷感） |
| 金融/效率/阅读 | Bento 格栅（仪表盘） | 极简奶油 / 瑞士大字报（阅读） | 黏土可爱（缺信任感） |
| 餐饮/怀旧 | 复古港风 | 国潮 / 千禧复兴（怀旧杀） | 暗黑霓虹 |
| 医疗/健康 | 新拟态 | 扁平插画（治愈系） | 暗黑霓虹（缺安全感） |
| 智能家居/工具 | Bento 格栅（中控） | 新拟态 | 复古港风 |
| 影像/播放器 | 液态玻璃 | 暗黑霓虹 | 瑞士大字报 |
| 学习打卡/健身 | 多巴胺 | 手绘风 | 极简奶油（缺激励感） |

铁律：一个 App 只用一套风格；营销弹窗（28）可跳出主风格做反差。

## 3. 反模式清单（设计师最常打回的）

1. **弹窗没有关闭方式**：任何弹窗必须有 X 或"知道了"，异形弹窗也不例外。
2. **价格只有一个数字**：秒杀/拼团必须价格三件套（原价删除线/券后价/秒杀价红），单个数字没有紧迫感。
3. **选中态只靠颜色**：色弱用户看不见。选中 = 颜色 + 形状变化（胶囊/下划线/加粗）二选一。
4. **吉祥物满屏乱飞**：一屏最多 2 只，每只必须有叙事任务（引导/庆祝/安慰），装饰性吉祥物是噪音。
5. **按钮文案是名词**："优惠券"不如"立即领券"。按钮文案永远是动词。
6. **空状态只有文字**："暂无数据"是最懒的设计。空状态 = 吉祥物 + 一句话安慰 + 一个 CTA。
7. **倒计时没有单位**："09:39:38"不如"仅剩 09:39:38"，用户需要知道这是什么倒计时。
8. **Tab 超过 5 个不横滑**：顶部 Tab 超过一屏必须可横滑，末尾露半个表示可滑。
9. **会员卡没有"还差多少"**：未达成态必须写"还差 X 升级"，这是转化的核心。
10. **深色模式直接反色**：暗黑霓虹不是"把白色变黑"，是独立的一套 token（见 style-variants.md）。

## 4. 设计师点评模式

拿到任何一稿，按这个顺序点评（对应 design-qa.md 的 10 项，但先讲"为什么"）：

1. **一眼任务**：3 秒内能说出这屏是干什么的吗？不能 → 信息层级错了，先修标题和 CTA。
2. **视线路径**：眼睛从哪到哪？吉祥物/大字/按钮三点是否形成三角？散了 → 收紧。
3. **一个动作**：这屏希望用户只做一件事，是什么？有两个 → 砍掉次要的。
4. **状态诚实**：按钮的禁用/加载态画了吗？没画 → 交互稿不合格。
5. **风格纯度**：有没有混入第二套风格的元素？有 → 统一。

点评话术模板："这屏的{问题}是因为{原因}，改成{方案}，用户会{收益}。"

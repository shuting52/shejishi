# 风格令牌（实测自 12 条可见笔记 + 主页截图）

## 封面公式（干货系列，占比最高）
| 位置 | 元素 | 规范 |
|---|---|---|
| 底色 | 纯黑底 | #000000，无渐变、无纹理 |
| 左上 | 描边胶囊标签 | 空心描边圆角胶囊，白字；文案二选一："设计细节" 或 "案例分享" |
| 右上 | 品类标识 | 白色小字 `-UI/UX` |
| 中央 | 大标题 | 白色粗黑体系列名 + 黄色关键词，格式：`设计赏析-关键词` / `设计参考-关键词`；偶有前缀如"蓝色系-" |
| 下方 | 截图矩阵 | 2 列 x 4 行 = 8 张同类组件截图，圆角卡片拼贴 |
| 底部 | 署名水印 | 小字署名 + 平台徽章（如"你的名字｜独立设计师"，换成自己的署名） |

黄色关键词：高饱和明黄，约 #FFD400，是全系最强记忆点。

## 封面变体
- **置顶原创改版**：浅色底（米白/浅灰）+ 2~3 台手机 mockup + 左上深色"置顶"胶囊 + 右上水印；大字为项目概念词（如"有里"+"体验改版原创设计"）。
- **IP/视觉实验**：可完全跳出黑底公式（彩色渐变底 + 立体大字 + 插画主体），但只做少量。

## 标题公式（实测）
- 干货系列：`💥设计赏析｜{组件名}` / `💥设计参考｜{主题名}`
- 原创项目：`原创设计｜{项目名}改版` / `速！{项目名}改版设计来咯`
- 教程类：`{主题}｜附教程`
- 视觉实验：口语化感叹句（如"哦吼！我居然也会做IP辣？"）

## 内容气质
- 选题颗粒度小：一次只讲一个组件（启动图标、底部TAB、积分签到、集卡、PK组件、天气控件、付费订阅……），不贪大。
- 封面即目录：8 张截图拼贴让读者一眼看到"干货密度"。
- 系列感 > 单篇爆款：统一封面模板形成矩阵，账号一眼可识别。

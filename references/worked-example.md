# 完整示例：原创笔记《搜索历史》（她没做过的组件）

## 输入
组件名：搜索历史

## 输出 1：cover-prompt.txt
（套用 cover-prompt-template.md，关键词=搜索历史；中文大字后期叠加）

## 输出 2：title.txt
```
💥设计赏析｜搜索历史
```

## 输出 3：body.md（正文骨架 + 原创拆解）
```
搜了 8 个 App 的搜索历史页，发现大家长得都不一样，细节全在魔鬼里。

1. 历史词的"可删性"：有的长按删除，有的一键清空，还有的左滑单条删——清空按钮放右上角最顺手。
2. 热搜和历史的分区：上下分区最常见，左右 tab 切换的最省空间。
3. 空历史状态：好的会放一句引导文案"试试搜索你感兴趣的内容"，差的直接空白。
4. 搜索框常驻：历史页保留顶部搜索框的，二次搜索少一步。

结论：搜索历史的核心是"删得爽、找得快"，交互成本越低越好。
想看哪个组件，评论区告诉我，下期安排。
```

## 输出 4：tags.txt（占位，等用户截图后替换）
```
#UI设计 #UX设计 #设计干货 #APP设计 #交互设计 #设计分享
```

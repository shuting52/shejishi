# 自动化流水线（v7 新增：输入项目名，全套自动生成）

v6 的模式 C 需要设计师一步步执行。v7 把它固化为流水线：**输入只有项目名**，
按 8 步自动产出，配合 `scripts/scaffold.py` 一键生成 pack 骨架。

## 流水线 8 步

```
项目名
  │ Step 1 品类识别：关键词匹配 → 品类（出行/餐饮/社交/电商/教育/运动/医疗/金融/游戏/工具）
  │ Step 2 风格推荐：查 design-principles.md §2 → 首选风格 + token 行
  │ Step 3 主题表生成：App 名（2 字）+ slogan + 风格 token + 吉祥物（按风格配）
  │ Step 4 IA 生成：4 Tab 骨架（首页/发现或行程/消息/我的）+ 品类核心页
  │ Step 5 组件映射：按品类查映射表 → 组件编号清单
  │ Step 6 逐屏 Prompt：组件库 Prompt + 风格 token 行 + 状态句式（component-states.md）
  │ Step 7 封面物料：黏土风封面公式 + 标题
  │ Step 8 验收 + 代码：design-qa.md 10 项 → code-bridge.md 出单文件 HTML
  ▼
project-pack.md + 可交互原型
```

## 脚本用法

```bash
python3 scripts/scaffold.py "打车"
# → 输出 project-pack-打车.md：主题表 + IA + 组件映射 + 逐屏 Prompt 骨架
```

脚本只做"骨架生成"，设计师（AI）再按骨架填血肉、跑验收、出生码。
全自动跑完 8 步 = v7 的"自动化"；人工只负责最后拍板。

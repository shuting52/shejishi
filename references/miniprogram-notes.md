# 小程序适配清单（微信小程序 vs App）

做小程序项目时，组件映射按此表调整。其余设计语言（风格 token、版式骨架、六态）与 App 完全通用。

## 不用的 App 组件

| App 组件 | 小程序替代 |
|---|---|
| 01 启动页 | 无。小程序冷启动 1–2 秒，用**骨架屏**代替 |
| 02 启动图标 | 无。用**小程序分享卡**（5:4）+ 小程序码 |
| 09 更新弹窗 | 无。微信自动静默更新；用顶部**版本提示条**代替 |
| 推送通知 | 用**订阅消息**（用户一次性授权，下单/取餐/拼团成功时触发） |

## 必须加的小程序约束

1. **避让胶囊按钮**：右上角微信胶囊（⋯ ✕）区域不可放标题/按钮，自定义导航栏时左侧留出返回+标题安全区
2. **底部安全区**：iPhone Home 条 + 微信无 Tab 时的底部间距，用 `env(safe-area-inset-bottom)`
3. **微信一键登录**：我的页顶部放"微信头像昵称一键获取"按钮，不做自建账号密码体系
4. **分享即增长**：拼团/拼单/优惠券必须有"分享给微信好友"底部弹窗（库04），分享卡带小程序码
5. **微信支付**：结算页支付方式默认微信支付，不画支付宝/银联选项
6. **Tab 最多 5 个**：常用 首页 / 分类 / 购物车（或订单）/ 消息 / 我的
7. **首屏秒开**：首屏只放骨架屏 + 核心流，图片用懒加载 + 占位色块

## 组件映射速查（小程序）

- 首页 → 25 顶部视觉（自定义导航栏避让胶囊）+ 26 TAB 切换 + 17 卡片设计
- 加购/规格 → 04 底部弹窗
- 结算 → 29 表单输入（备注、取餐方式、手机号授权）
- 订单 → 31 订单卡片（进行中/待取货/已完成/退款中四态）
- 取餐码/提货码 → 28 异形弹窗（大字取餐码 + 条形码）
- 拼团进度 → 28 异形弹窗（还差 N 人 + 倒计时 + 分享 CTA）
- 秒杀 → 24 秒杀/拼团
- 公告 → 08 跑马灯（门店公告/平台公告）
- 空态 → 30 空状态与异常页（无订单/无优惠券/网络异常 + 订阅消息兜底）
- 我的 → 20 个人主页（微信头像昵称区 + 订单/优惠券/客服/订阅消息管理）

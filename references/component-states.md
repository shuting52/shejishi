# 组件状态矩阵（v7 新增：交互稿的及格线）

设计师铁律：**没有状态的组件是半成品**。每个组件出 Prompt 时，必须写明六态。
六态：默认 / 选中（激活）/ 禁用 / 空 / 加载 / 错误。不是每个组件六态全有，下表标出必备态。

## 状态通用写法
- **选中**：颜色变化 + 形状变化（加粗/胶囊/下划线）二选一，不只靠颜色（反模式 #3）
- **禁用**：灰化 + 不可点，配一句原因（"还差 2 单升级"比纯灰好）
- **空**：吉祥物 + 一句话安慰 + 一个 CTA（反模式 #6）
- **加载**：骨架屏优先于转圈，转圈只用于 < 1s 的操作
- **错误**：说人话（"网络开小差了"）+ 重试按钮，不甩错误码

## 出 Prompt 时的状态句式

在每份 UI 生成提示词末尾加一段（按上表挑必备态）：

```
States: default + selected (capsule highlight + bold black text, not color-only)
+ disabled (grayed with reason "还差 2 单升级")
+ empty (mascot + "还没有内容" + CTA "去看看").
```

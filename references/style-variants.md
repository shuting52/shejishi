## 使用方法
- 组件 Prompt 开头加一行：`Style: {风格名}，tokens: {对应 token 行}`。
- 写代码直接查上表，颜色/圆角/阴影/字体照抄。
- 项目全案模式 C：在主题变量表里加一行"风格"，整套 Prompt 统一引用。
- 封面物料不受风格变量影响，永远走黏土风封面公式（黑底+黄标题）。
- 一稿多风格：同一套组件 Prompt 换 token 行即出 14 版，直接拼单。

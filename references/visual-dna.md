# 真·视觉 DNA（用户提供的 5 张正文截图，2026-10-15）[实测]

> 这是之前缺失的"内功"。v1–v3 只吃透了她的封面（货架），这 5 张揭示了她的内页设计语言。
> 样图存于 references/samples/。

## 一句话风格
**可爱 3D 黏土风 + 粗黑描边贴纸感**：白团子角色、对话气泡、高饱和渐变，可爱但排版极克制。

## 角色语言
- 主体：白色圆润团子，极简五官（两点眼 + 弧线嘴），偶尔腮红
- 描边：粗黑线勾边，贴纸感，表情靠五官微调（wink/张嘴/眯眼）
- 质感：3D 黏土/软胶，高光 + 柔和渐变，chunky 圆润
- 吉祥物：毛茸茸小怪兽探头杀（租房筛选那张：黄毛团子扒着卡片上沿，配房子+行李箱插画）

## 装饰语言
- 对话气泡：黑底白字或白底描边，内写 "Hi~" / "YEAH!" / "wow" / "求分享~" / "赞！"
- 点缀：四角星、腮红、波浪线、小插画（铅笔、房子）
- 英文手写感点缀，中英混排不违和

## 背景语言
- 浅色版：奶油黄 / 蜜桃粉 / 薄荷绿 / 天空蓝的高饱和渐变
- 深色版：纯黑 / 藏青底 + 明黄 #FFD400 高亮（与封面公式同源）
- 键盘皮肤证明：同一套设计有浅（橙黄黏土）深（巧克力）两版，切换只换底色+按键色，角色语言不变

## 字体语言
- 中文：大字粗黑标题，字号对比强烈
- 按钮：渐变胶囊（绿→蓝），白色描边小字

## 组件语言（可直接复用）
- 选项卡：选中项用**黄色异形标签**（如"合租"的不规则黄块）突出，其余灰字
- 卡片：白色圆角大卡 + 黄色描边点缀，吉祥物探头打破矩形边界
- 键盘：3D 黏土按键，字母撞色（每个字母不同 pastel 色），功能键纯色强调

## 封面与内页的关系
封面（黑底+黄字+截图矩阵）是货架，负责在信息流里被看见；
内页（黏土乐园）负责让人"哇"出来。**反差即记忆点**，做内容时两套都要。

## 应用到项目（如"今天吃什么"）
- 把"食欲感"翻译成"可爱食欲感"：奶油底 + 3D 黏土美食图标（汉堡/火锅团子化）+ 粗黑大标题 + 气泡装饰
- 转盘格子：每个菜系画一个团子形象，而不是纯文字格
- 主色番茄红保留，作为"选中/CTA"的黄色位等价物（或直接引入她的明黄做点缀）
- 深色模式：照搬她的巧克力/藏青深色版逻辑

## 弥散渐变语言（配色篇）
- 载体：深色圆角大卡片（近乎黑），顶部斜插一张"标签纸"（白+ pastel 色双层）
- 排版：左上 "UI设计-配色篇" 白字 + 右上 "-UI/UX"；卡片内手写体 "Hello!" + 大号粗黑 "弥散渐变"
- 渐变：aurora/mesh 弥散，从卡片底部向上晕染（橙黄组 / 蓝紫组 / 粉紫组 / 青绿组）
- 色点：底部 3 个白描边色圆 + hex 标注（如 #FF0065 #C300FF #FF438D）
- 点缀：极细的白色弧线（2-3 条），呼吸感
- 用法：做 App 的主题配色展示、开屏背景、活动头图

## 引导页语言（新手引导 / coach mark）
- 封面公式：黑底 + 白色大字"引导页" + 白色短横线 + 右上斜体英文 "Introduction page'"
- 内页手法：全屏深色遮罩 + 被讲解的卡片高亮 + 气泡 tooltip（蓝底白字 / 黄底黑字）
- 气泡文案：口语化一句 ("欢迎来到您的专属领地！") + 操作按钮（"下一步 1/2" 红色胶囊 / "我知道了" 描边胶囊）
- 吉祥物：粉色云朵小怪、蓝色 Hello 气泡，每张引导只讲一件事
- 适用：新功能上线、会员体系讲解、复杂活动规则

## 启动图标语言（补充）
- 三色系：明黄系 / 红粉系 / 天空蓝系，纯色底 + 粗黑描边
- 主体：白团子动物（鸭/猫/猪/熊/幽灵）+ 大眼睛 + 腮红，偶尔配英文词（Hi / YO! / Meh / Wefun）
- 共同点：形象占满图标 80%，无小字，3 米外可识别

## 启动页语言（补充）
- 2x4 矩阵：每张都是"吉祥物 + 一句 slogan + 品牌 logo"，pastel 底
- 吉祥物即品牌：皮皮（耳机爱心）、咕咚、咕嗒（星球），先记住脸再记住名

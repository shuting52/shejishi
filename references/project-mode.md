# 项目全案模式（模式 C）

输入一个项目（如"房屋出租"），自动输出整套 App 的交互设计。

## 流程 5 步

### 第 1 步：定主题（主题变量表）
先输出一张主题表，后续所有 Prompt 都引用它：
| 变量 | 示例（房屋出租·安住） |
|---|---|
| App 名 | 安住 |
| slogan | 好房子，不将就 |
| {主色} | #FF5A1F 活力橙 |
| {深色} | #101828 藏青 |
| {背景色} | #F6F7F9 |
| {圆角} | 16px 卡片 / 12px 按钮 |
| 风格关键词 | 真实房源大图、价格大字、地图找房、年轻化 |

### 第 2 步：画 IA（信息架构树）
输出 Tab 结构 + 核心页面 + 弹窗 + 活动，示例：
```
安住
├─ 启动页 → 首页
├─ Tab：首页 / 地图 / 消息 / 我的
│  ├─ 首页：搜索栏、跑马灯公告、快捷筛选、房源卡片流
│  ├─ 地图找房：地图+价格气泡、底部房源卡片
│  ├─ 消息：会话列表
│  └─ 我的：个人主页、积分签到、会员订阅、设置
├─ 房源详情页 / 搜索页 / 筛选页 / 预约看房页
├─ 弹窗：筛选底部弹窗、联系房东底部弹窗、更新弹窗
└─ 活动：租房节集卡
```

### 第 3 步：列清单（页面 → 组件库映射）
每个页面标注来源：`[库01]`=组件库编号，`[定制]`=项目特有需单独写。
| 页面 | 来源 |
|---|---|
| 启动页 | 库01 |
| 启动图标 | 库02 |
| 首页 | 定制（搜索+跑马灯+筛选+房源流组合） |
| 房源详情页 | 定制 |
| 地图找房页 | 定制 |
| 预约看房页 | 定制（时间选择） |
| 底部Tab | 库03 |
| 筛选底部弹窗 | 库04 |
| 个人主页 | 库10 |
| 积分签到 | 库11 |
| 会员订阅 | 库15 |
| 更新弹窗 | 库09 |
| 集卡活动 | 库13 |

### 第 4 步：逐屏出 Prompt
每个屏幕一份：**屏幕目标**（一句话）+ **UI 生成提示词**（主题变量已填入，直接投喂）+ **黏土风封面**（卡片编号 + 标题）。

定制页面的 Prompt 写法：沿用组件库的 prompt 结构，把项目业务元素填进去
（房源卡片 = 大图+价格大字+户型标签+距离；详情页 = 图集+价格+设施图标+位置+预约 CTA）。

### 第 5 步：打包 project-pack.md
```
# 《App名》设计全案
## 主题变量表
## IA 树
## 逐屏 Prompt 清单（每屏：目标 / UI prompt / 封面卡 / 黏土风标题）
## 黏土风系列标题清单（可直接做成内容连载）
```

## 规则
1. 主题先行：所有屏幕 Prompt 的颜色/圆角/字体必须引用主题变量表，不许每屏各一套。
2. 封面系列化：项目全案的每屏封面用同一版式（默认卡片 A），标题统一为 `💥设计赏析｜安住·{屏幕名}`，形成连载矩阵。
3. 业务真实：房源价格/户型/地名用合理示例数据，不写"XXX"占位。
4. 完整示例见 [project-example-house-rental.md](project-example-house-rental.md)。
